## 🌤️ weather-app — 오늘의 날씨

- 도시 검색 / 현재 위치 날씨, 시간별·7일 예보
- 어제 같은 시각과 기온 비교 (▲ 더 따뜻 / ▼ 더 추움)
- 우산 챙길지 알려주기 (오늘 남은 시간 강수확률·강수량 기준)
- 주식 시장: 코스피, 코스닥, 삼성전자, S&P 500, 나스닥, 원/달러 환율
- 오늘 받은 네이버 메일 수 (IMAP)

**🌐 배포판:** https://wpzl03.github.io/exe/weather-app/ (날씨·어제 비교·우산 알림)

**내 PC에서 전체 기능 실행:** `weather-app/실행.bat` 더블클릭 → 브라우저에서 `http://localhost:8000` 이 열림
(주식·네이버 메일 수는 이 방법으로 열었을 때만 나옴)

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 (HTML/CSS/JS) |
| `serve.ps1` | 로컬 서버: 화면 제공 + 주식 시세 중계(CORS 우회) + 메일 수 확인 |
| `naver-mail.ps1` | 네이버 메일 IMAP 접속 함수 |
| `실행.bat` | 서버 실행 바로가기 |

자료: [Open-Meteo](https://open-meteo.com) (날씨), Yahoo Finance (주식)

## 🌾 farm-orders — 농산물 직거래 주문관리

문자·카톡 주문 → 엑셀 주문장 → 입금 확인 → 발송까지 한 화면에서 처리합니다.

1. **주문 입력** — 받은 메시지를 붙여넣으면 이름·연락처·주소·품목·수량을 자동으로 읽음 (단골 고객은 주소 자동 채움)
2. **주문 목록** — 입금대기 → 입금확인 → 발송완료 상태 관리, 고객 안내 문자 복사
3. **입금 확인** — 인터넷 뱅킹 거래내역/입금 알림 문자를 붙여넣으면 입금자명+금액으로 주문과 대조
4. **발송** — 포장 목록 인쇄, 택배 접수용 엑셀, 송장번호 입력, 발송 안내 문자
5. **엑셀** — 주문장(.xlsx) 저장·불러오기

**실행:** `farm-orders/index.html` 더블클릭 (서버 필요 없음, 엑셀 기능은 인터넷 연결 필요)

데이터는 브라우저(localStorage)에 저장되므로 주기적으로 엑셀로 백업하세요.
