## 자주 쓰는 명령
```powershell
git status                 # 바뀐 파일 보기
git add .                  # 올릴 파일 담기
git commit -m "고친 내용"   # 기록 남기기
git push                   # 깃허브에 올리기
git pull                   # 깃허브 내용 가져오기
```
push 하고 1~2분 뒤 배포 사이트에 반영돼요.
