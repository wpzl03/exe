# 🌾 직거래 주문관리 앱

← [[오늘의 작업 정리 2026-11-07]] · 관련: [[기획안 - 주문관리 시스템 도입]], [[보고서 - 국내 직거래 프로그램 현황]]

- **배포 주소:** https://wpzl03.github.io/exe/farm-orders/
- **코드:** `farm-orders/index.html` (파일 하나, 더블클릭으로 실행)

## 하루 흐름
1. **주문 입력** — 문자·카톡을 붙여넣고 「자동으로 읽기」 → 저장 → 입금 안내 문자 복사
2. **입금 확인** — 은행 거래내역·입금 알림 붙여넣기 → 입금자명+금액 자동 대조
3. **발송** — 포장 목록 인쇄, 택배 접수 엑셀, 송장번호 → 발송 안내 문자
4. **마감** — 📥 엑셀로 저장 (백업)
