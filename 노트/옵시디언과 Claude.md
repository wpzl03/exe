## Claude와 연동하는 3가지 방법
1. **같은 폴더 함께 쓰기 (지금 쓰는 방식)** — 보관함 = `03_수업자료`. Claude가 만든 `.md` 가 옵시디언에 바로 보이고, 옵시디언에서 쓴 노트를 Claude가 읽는다. 설치·비용 없음.
2. **옵시디언 AI 플러그인** — 옵시디언 안에서 Claude 호출. Anthropic API 키가 따로 필요하고 사용량만큼 요금.
3. **MCP 연결** — 플러그인 + MCP 서버로 Claude 앱이 노트를 검색·작성. 설정이 복잡.

## 알아 둘 것
- 옵시디언에서 **PDF는 보기·주석만** 가능, 글자 수정은 안 됨 → 원본(`docs/*.html`)을 고쳐서 PDF를 다시 만든다.
- 옵시디언 설정 폴더 `.obsidian/` 은 깃허브에 올리지 않는다 (`.gitignore` 등록).
- Claude에게 "노트 만들어줘"라고 하면 `노트/` 폴더에 만들고 관련 노트와 링크로 연결한다 ([[CLAUDE]] 규칙).
