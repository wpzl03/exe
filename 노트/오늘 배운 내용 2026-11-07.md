## 1. 날씨앱 — 웹 앱의 기본

- **HTML 파일 하나**에 화면(HTML)·꾸밈(CSS)·동작(JavaScript)을 모두 넣을 수 있다.
- 날씨는 **Open-Meteo**처럼 API 키 없이 쓰는 무료 서비스에서 가져왔다(`fetch`).
- **API도 한계가 있다:** 도시 검색이 한글 이름("서울")을 못 찾음 → 자주 쓰는 도시를 영어로 바꾸는 **변환표**를 만들어 해결.
- **어제와 비교:** `past_days=1` 로 어제 데이터까지 받아서 "어제 이 시간보다 2° 낮아요" 표시.
- **우산 판단:** 오늘 남은 시간의 강수확률·강수량으로 ☔ 꼭 / 🌂 있으면 좋음 / 😎 필요 없음.
- **CORS(교차 출처 정책):** 브라우저는 보안상 다른 사이트(주식 사이트)에 마음대로 요청하지 못한다 → 내 PC에 **작은 서버(`serve.ps1`)**를 띄워 서버가 대신 가져오게 함.
- **로그인 정보는 다른 프로그램이 못 빌려 쓴다:** 브라우저에 로그인된 네이버를 앱이 읽을 수 없음 → 네이버 메일은 **IMAP**으로 따로 로그인.
- **비밀번호는 채팅에 쓰지 않는다.** 앱 화면에서 입력 → PC에 **암호화(Windows DPAPI)**해서 저장.

## 2. 직거래 주문관리 앱 — 업무 자동화

- **자동화의 한계를 먼저 확인:** 카카오톡(개인)·인터넷 뱅킹은 외부 연동이 안 된다 → **복사·붙여넣기 + 자동 읽기** 방식이 현실적인 답.
- 메시지에서 이름·전화·주소·품목·수량을 찾는 데 **정규식(패턴 찾기)**을 썼다.
  - "배 두 박스" → 한글 숫자도 인식, "택배"·"배송"의 "배"는 상품으로 안 봄
- 데이터는 **브라우저 저장소(localStorage)** → 다른 PC/브라우저에는 없음 → **매일 엑셀로 백업**.
- 엑셀(.xlsx) 저장·불러오기는 **SheetJS** 라이브러리.
- **입금 대조:** 은행 문자를 붙여넣으면 *입금자명 + 금액*이 같은 주문을 찾음. 금액만 같으면 "확인 필요"로 따로 표시.
- **테스트의 중요성:** 헤드리스 브라우저로 예시 메시지를 돌려 보다가 "주소 뒤에 품목이 붙는" 버그를 찾아 고쳤다.
- 운영 팁: 카카오톡 PC버전, Windows「휴대폰과 연결」(문자 복사), 은행 입금 알림, 계약 택배, 고객용 **주문 양식** 배포.

## 3. 깃허브와 배포

- `winget install --id Git.Git` 으로 git 설치.
- 기본 흐름: `git add .` → `git commit -m "메시지"` → `git push` / 받아오기는 `git pull`.
- **`.gitignore`**: 올리면 안 되는 파일(로그인 정보, 고객 엑셀, 옵시디언 설정)을 막는다. 단, **깃허브 웹사이트에 직접 끌어다 올릴 때는 적용 안 됨!**
- 로그인 창이 안 뜰 때는 **기기 코드 방식**(github.com/login/device 에 코드 입력).
- **`.bat` 파일에 한글을 쓰면 깨져서** 명령이 잘린다 → bat 파일은 영어로만.
- **깃허브 페이지(무료)는 공개 레포만** 가능 → 공개로 바꾸고 Settings › Pages 에서 `main` 선택.
  - 배포 주소: `https://wpzl03.github.io/exe/weather-app/`
- 배포판에서는 내 PC 서버가 없으니 주식·메일 수는 자동으로 숨기게 했다.

## 4~5. 기획안·보고서(PDF) 만들기

- **기안서 구성:** 결재란(담당·차장) → 문서 정보 → 본문 1·2 → `- 아 래 -` 요약표 → 붙임 → 세부 기획안(배경·목적·개요·비교·효과·예산·일정·위험·요청).
- **보고서 구성:** 핵심 요약 → 개요 → 현황 → 유형별 표 → 시사점 → 조사의 한계 → 참고 자료.
- **신뢰를 지키는 작성법**
  - 모르는 정보는 지어내지 않고 `(작성)` 빈칸으로
  - 추정치는 *가정*을 밝힌다 ("하루 20건 가정")
  - 공식 통계가 아닌 수치(언론·업체 발표)는 `※` 표시 + 「조사의 한계」에 기록
- **만드는 방법:** HTML로 문서를 만들고 → **Edge로 PDF 인쇄** (Python 없이도 가능).
- **검수:** PDF를 쪽마다 이미지로 바꿔서 직접 확인 → 표 오른쪽 테두리 잘림, 빈 쪽, 화면 캡처 속 버그를 찾아 고침.
- **PDF는 직접 고치는 게 아니라** 원본(`docs/*.html`)을 고쳐서 다시 만든다. (예: 이름을 "친환경농산물"로 변경)

## 8. 원격 접속 — Tailscale + SSH

- **Tailscale:** 내 기기들끼리만 쓰는 **사설 네트워크**. 같은 계정으로 로그인하면 기기마다 `100.x.x.x` 주소가 생긴다.
  - 이 PC `100.79.255.74`, 휴대폰(s25) `100.118.80.127`
- **SSH 클라이언트**(접속하는 쪽)는 Windows에 기본 설치, **SSH 서버**(접속받는 쪽)는 따로 설치해야 한다.
- Windows 기본 설치 방식이 다운로드 49%에서 멈춤 → **마이크로소프트 공식 OpenSSH 설치 파일**로 설치해 해결.
- **보안:** 방화벽에서 **Tailscale 주소(100.64.0.0/10)에서 오는 접속만 허용**.
- 접속: `ssh wpzl1@100.79.255.74` + Windows(Microsoft 계정) 비밀번호. *PIN은 안 됨.*

## 9. Claude와 일하는 법 (덤)

- 로그인, 관리자 권한 승인(UAC), 비밀번호 입력처럼 **본인이 직접 해야 하는 일**이 있다.
- 외부에서 PC에 접속할 수 있게 여는 작업(SSH 서버 등)은 **보안상 자동 실행이 차단**될 수 있다 → 직접 요청하거나 직접 실행.
- 결과는 "됐다"는 말보다 **실제로 확인**하는 게 중요하다 (사이트 접속, 테스트, 쪽 렌더링, 접속 기록).

## 🔧 오늘 겪은 문제와 해결

| 문제 | 원인 | 해결 |
|---|---|---|
| "서울"이 검색 안 됨 | 날씨 검색 API가 한글 미지원 | 한글→영어 도시 변환표 |
| 주식 정보를 못 가져옴 | 브라우저 CORS 보안 | PowerShell 로컬 서버가 중계 |
| 메일 수가 안 나옴 | 로그인 정보 미저장 | 앱 화면에서 로그인 → 암호화 저장 |
| 깃허브 로그인 창이 안 뜸 | 숨은 창에서 실행됨 | 기기 코드 로그인 |
| bat 파일 실행 시 이상한 글자 | bat 안의 한글이 깨짐 | 영어로만 작성 |
| PDF 표 테두리 잘림 | 표 폭 100% | `calc(100% - 2px)` |
| PDF에 큰 빈 쪽 | 긴 표가 통째로 넘어감 | 표를 쪽 나눔 허용 + 제목 줄 반복 |
| 주소 뒤에 "고구마 2박스" | 자동 읽기 규칙 부족 | 규칙 수정 + 테스트 6개 |
| PDF 스크립트 오류 | PowerShell 5.1 특성 | 저장 위치 계산 위치 변경 |
| SSH 서버 설치가 49%에서 멈춤 | Windows 업데이트 다운로드 정지 | 공식 MSI로 설치 |
