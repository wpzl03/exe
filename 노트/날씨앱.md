# 🌤️ 날씨앱

← [[오늘의 작업 정리 2026-11-07]]

- **배포 주소:** https://wpzl03.github.io/exe/weather-app/
- **코드:** `weather-app/index.html`

## 기능
- 도시 검색(한글 가능), 📍 현재 위치
- 현재 날씨, 시간별(24시간)·7일 예보
- **어제와 비교:** "▼ 어제 이 시간보다 2° 낮아요", 어제/오늘 최고·최저
- **우산 알림:** 오늘 남은 시간 강수확률·강수량으로 ☔ 꼭 / 🌂 있으면 좋음 / 😎 필요 없음
- **주식:** 코스피, 코스닥, 삼성전자, S&P 500, 나스닥, 환율 — 내 PC 서버로 열 때만
- **네이버 메일 수:** "오늘 받은 메일 N통" — 내 PC 서버로 열 때만

## 실행 방법
| 방법 | 되는 기능 |
|---|---|
| 배포 주소로 접속 | 날씨, 어제 비교, 우산 |
| `weather-app/실행.bat` 더블클릭 | 전부 (주식·메일 포함) |

- 날씨: Open-Meteo (API 키 필요 없음)
- 주식: Yahoo Finance (서버가 대신 가져옴)
